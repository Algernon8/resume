# 池一鸣 · YIMING.CV

一个像素风格的个人品牌主页，带星露谷风格的栽树小游戏。访问地址：`https://algernon8.github.io/resume/`

## ✨ 特色

- 🎨 **像素风设计** — 复古游戏美学，和市面上千篇一律的简历不一样
- 🌱 **栽树小游戏** — 用方向键移动像素小人，空格键种树，种满所有树解锁彩蛋
- 📊 **数据可视化** — 关键数字滚动计数动画
- 🌓 **明暗模式** — 支持浅色/深色切换，自动保存偏好
- 📱 **响应式** — 桌面端、平板、手机都能看，移动端有触屏游戏按钮
- 🖼️ **画廊板块** — 预留照片/视频展示位

## 🖼️ 怎么换照片

### 头像和生活照

把你的照片放进 `images/` 文件夹，文件名对应：

| 文件 | 用途 | 建议尺寸 |
|------|------|----------|
| `avatar.jpg` | Hero 区大头像 | 方形，400x400 以上 |
| `photo-1.jpg` | 生活照小缩略图 1 | 方形即可 |
| `photo-2.jpg` | 生活照小缩略图 2 | 方形即可 |
| `photo-3.jpg` | 生活照小缩略图 3 | 方形即可 |

> 没有上传的照片会自动显示占位符，不影响页面显示。

### 项目封面图

把项目截图或封面图放进 `images/` 文件夹：

| 文件 | 对应项目 | 建议尺寸 |
|------|----------|----------|
| `project-afft.jpg` | AFFT 大赛 | 800x400，横图 |
| `project-absence.jpg` | 智慧假勤系统 | 800x400，横图 |
| `project-ai.jpg` | 长江灵曦智能体 | 800x400，横图 |
| `project-competition.jpg` | 学创杯 | 800x400，横图 |

### 画廊照片

把任意照片/视频放进 `gallery/` 文件夹，命名为 `1.jpg`、`2.jpg` ... 一直到 `9.jpg`（也支持 `.png` 和 `.mp4`）。

- 支持 9 个格子
- 点击可以放大查看
- 支持视频（`.mp4` 格式，第 9 格预留为视频位）

## 🎮 小游戏说明

### 玩法
- **← → 方向键** 或 **A / D 键**：控制像素小人左右移动
- **空格键**：在当前位置种一棵树
- 每个区域对应一种不同的树，共 7 棵
- 种满所有树会触发 🎉 通关彩蛋

### 移动端
- 页面底部有左右移动按钮和种树按钮
- 触屏操作即可

### 进度保存
- 种树进度自动保存在浏览器 localStorage
- 下次打开页面继续你的进度
- 清除浏览器数据会重置

## 🚀 部署到 GitHub Pages

1. 推送代码到 GitHub 仓库（已经在 `main` 分支了）
2. 仓库 Settings → Pages
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main` / `(root)`
5. 保存，等几分钟就可以访问了

## 🛠️ 自定义修改

所有代码都在 `index.html` 一个文件里，直接用文本编辑器打开改就行。

- **改文案**：直接搜对应的文字替换
- **改颜色**：文件开头 `:root` 里的 CSS 变量
- **加板块**：复制一个 `.section` 结构改内容
- **改游戏**：搜 `PIXEL FARMER GAME` 注释
